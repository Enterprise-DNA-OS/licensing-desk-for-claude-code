# A licensing desk without a front end

The operator asks the coding agent to read applications, prepare the evidence queue, record an inspection result or draft the weekly review. The database holds the records. The agent uses one CLI and shows its results. Read-only HTML views and working papers are printed or opened locally.

A public portal provides self-service intake, a phone app captures field evidence and an interactive map supports geographical work. This build has none of those. It also has no offline sync, drag and drop, automatic notifications or payments. It is useful for an internal desk entering records and processing existing exports without any of those services.

Enterprise DNA can build the public intake, connections, screens and access controls your version needs. Agree their scope before replacing a live public service. The free database and workflow are the starting point.
